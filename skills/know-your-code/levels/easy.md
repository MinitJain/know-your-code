# Easy

1. Ask 3 multiple-choice questions on the diff. 4 options each, one correct. Make wrong options plausible, not silly.
2. After each pick: wrong → give a hint and let them pick again. Second miss → explain the answer.
3. Then ask one open line: "In one sentence, why did this change need to happen?"
4. Pass = all 3 MCQs resolved + a sensible one-line why.

Format:
```
Q1. What does retryFetch() do when the request fails?
  a) Throws immediately
  b) Retries with growing delay
  c) Retries forever with no delay
  d) Logs and returns null
```
