# Medium (default)

Ask exactly 3 open questions, each tied to a specific file/function in the diff:

1. **What** — what does this code do now that it didn't before?
2. **Why** — why this approach? (why back off, why this data structure, why here)
3. **What breaks** — what happens on failure, bad input, or concurrency? What would break if this line were removed?

No hints up front. Pass = core idea right on all 3 (follow-ups allowed per SKILL.md).
